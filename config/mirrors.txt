# 仓库文件的访问地址模板。每行：名称|模板
# 可用占位符：
#   {slug}   = owner/repo      {branch} = 分支名
#   {path}   = 文件路径        {u}      = 完整的 raw 地址
#
# 全部经过实测（2026-10-21 从本机逐个 curl）。
# 排序按实测响应速度从快到慢，程序输出地址清单时沿用这个顺序。
#
直连|https://raw.githubusercontent.com/{slug}/{branch}/{path}
ghproxy.net|https://ghproxy.net/{u}
ghfast.top|https://ghfast.top/{u}
gh-proxy.com|https://gh-proxy.com/{u}
jsDelivr|https://cdn.jsdelivr.net/gh/{slug}@{branch}/{path}

# ---------- 使用说明 ----------
# jsDelivr 走的是 CDN 缓存，对分支内容最长缓存 12 小时。
# 本仓库每两天更新一次，作为备用通道完全够用，
# 但它在 CDN 上的副本会滞后于仓库，别拿它当主用。
#
# 想临时禁用某个站，在行首加 # 即可，下次运行生效。
